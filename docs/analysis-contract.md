# 分析资料与解释边界

## 试点合同
trial 的 invited_arm 是随机分配，received 是实际参加；propensities 给出当时符合资格的邀请概率。assignment_unit 是 student，student_id 可跨期重复。outcome_available_at 在截止后者属于未成熟结果。邀请产生 slot_cost，即使学生未到场也占用安排容量。
## 决策对象
优化目标是邀请策略对结课结果的净价值，不能从邀请资料直接声称参加行为的因果效应。候选选择、超参数选择和最终价值判断要有可解释的隔离；策略应能对符合资格的新记录产生草案，非法臂或预算超限由既有分配台拒绝。允许比较多种方法，不要求一种预先给定的学习器。
## 检查边界
随机化概率已知的小资料可对照固定策略的设计估计。改变保留结果不能反向改变已冻结候选；学生多期记录应整体隔离。analysis_cases 包括无处理差异、预算不足、某臂在目标人群无支持和未成熟结课，均不预设是否推荐上线。
